Who it's for

如果你属于这三种人，这个工具就是为你写的

它不负责让判断变准，只负责让「判断错了」这件事的代价变小。

A

手感相反型

看多的时候它就跌，看空的时候它就涨。方向其实没判断错，只是进场的时点总跟行情错开一步。 工具不跟你讨论行情，你进场，它就把仓位翻到另一边。

B

反应慢半拍型

发现自己做反了，切页面、找撤单、填数量、确认下单——四步走完，行情已经跑出几十个点。 这四步交给程序，你只需要在 App 里点那一下。

C

高频试错型

一天要反手七八次，每次手动操作都在付滑点和手续费。机器执行的一致性， 比你第十次操作时的手速可靠。

它不做什么 不预测行情、不判断方向、不替你做决策、不看 K 线。它只在你说「我下了一单」之后， 把这单反着再做一遍。判断永远是你的，执行交给机器。
Problem

手动反手，慢的不是手，是流程

发现方向做反了，到真正拿到反向持仓，中间有三个不可压缩的动作。 行情不会等你把这三个动作做完。

手动反手 · 约 5 秒

  1. 发现方向做反，切到交易页
  2. 撤掉挂单 / 市价平掉已成交仓位
  3. 重新选择方向、填写数量、确认下单
  4. 滑点已经发生，且每一步都可能点错

反向开单器 · 一步

  1. 你在 OKX App 或网页照常下单
  2. 引擎检测到增仓单并自动接管
  3. 自动判断走「撤单或平仓 + 反向开」
  4. 反向持仓到位，全程不需要你操作
How it works

四步闭环，每一步都有明确边界

引擎不猜测你的意图，只对「订单」这个事实做反应，因此行为可预测、可复现。

STEP 01

监听

轮询订单列表做差量比对，启动时将存量订单全部标记为已知，历史单不会被误伤。

STEP 02

判定

反推成交前持仓，判断这笔单是增仓还是减仓。减仓单直接放行，不介入。

STEP 03

执行

限价单未成交则撤单后 1:1 反向；市价或已成交则按 2 倍成交量反向，实现净持仓翻转。

STEP 04

闭环

反向单带专属标签，被引擎自身识别并跳过，不会触发二次反手。

Capabilities

为真实盘面写的，不是演示稿

01

净持仓模式适配

OKX 买卖模式下，1:1 反向只会平仓归零。引擎按 2 倍成交量下单，才能真正拿到反向持仓。

02

市价单也能反

市价单是 IOC，物理上无法撤销。引擎自动改走「平仓 + 反开」路径，不再依赖撤单接口。

03

平仓单放行

用成交前持仓判定减仓单，避免「平不掉仓」的死锁。你能正常开仓，也能正常平仓。

04

合约面值计算

名义价值按「张数 × 合约面值 × 价格」计算，每张 ETH 是 0.1 ETH 而非 1 ETH，不会算错。

05

撤单异常全覆盖

处理 51403、51413（不可撤）、51400、51405（已成交）、51410（撤单在途）等真实错误码。

06

Builder 归因

下单请求自动携带 AI Builder Code（tag 字段），交易可被工作台识别并计入返佣。

Guard rails

防循环做在代码层，不靠配置

自动反手最大的风险是自己的单被自己反手。引擎用三层机制保证这件事不会发生。

LAYER 1

订单标签识别

引擎下的每一张单，clOrdId 强制以固定前缀开头。检测到该前缀直接跳过，从源头切断循环。

LAYER 2

同品种互斥锁

同一合约的反手执行期间加锁，并发的第二笔不会交叉下单，避免持仓被算错。

LAYER 3

启动基线

启动时先拉取存量订单建立白名单，只有启动之后新出现的单才会被处理。

Quick start

零依赖，Node 直接跑

只需要 Node 18 以上版本，不需要安装任何 npm 包。

# 1. 克隆
git clone https://github.com/tsnslj/okx-reverse-order.git
cd okx-reverse-order

# 2. 配置凭证（只开读取 + 交易权限，切勿开启提币）
cp .env.example .env

# 3. 先跑只读体检，确认账户模式与持仓
node scripts/p0-check.js --live

# 4. 演练模式：只检测不下单
node src/start.js

# 5. 确认无误后切实盘
node src/start.js --live
接口用途
POST /api/v5/trade/order反向开仓，携带 tag 归因
POST /api/v5/trade/cancel-order撤销未成交限价单
GET /api/v5/account/positions读取净持仓，判定增仓或减仓
GET /api/v5/trade/orders-history轮询差量，发现新订单
GET /api/v5/public/instruments读取合约面值与下单精度
