API 凭证

已保存的 Key 不会回显，留空表示不修改。
创建 Key 时你自己设的密码，OKX 后台查不到，忘了只能重建 Key。
默认「自动」就行。程序内置直连通道，会自动绕开国内对 OKX 域名的干扰，绝大多数人不需要代理。
直连能通就不用填。填了之后，「自动」模式下只在直连失败时才启用。

交易参数

填了之后每笔下单自动带上 tag，OKX 才会统计返佣。
越小越快，但也越费请求。1500 大约 2 秒发现新单。
关上就是演练模式：照常检测、照常算反向单，但不会真下单。
